# 🌌 Гравитационные войны (Gravity Wars)

Двупользовательская космическая аркада с честной симуляцией физики гравитационного притяжения планет, умными ИИ-ботами и динамическими пауэрапами. Вы играете за космический корабль, который должен уничтожить противника, маневрируя в условиях сложного гравитационного поля звездной системы.

## 🛠️ Стек технологий

* **Язык разработки:** Python 3.10+
* **Графический движок:** PyQt5 (`QPainter`, `QRadialGradient`, адаптивная экранная сетка).
* **Сборщик/Конфигурация:** PySide6/QtQuick (`pyproject.toml`, подготовлен шаблон для декларативного UI).
* **Математика и физика:** Векторная физика Ньютона (`math`, `random`), симуляция траекторий в реальном времени.
* **Сохранение данных:** JSON (`gw_scores.json`) для хранения таблицы рекордов и лучших пилотов.

## 🚀 Ключевые особенности игры

1.  **Реалистичная гравитация:** Каждая планета обладает уникальной массой и радиусом. Снаряды, ракеты и корабли притягиваются к космическим телам по закону всемирного тяготения Ньютона.
2.  **Адаптивный экранный интерфейс (Responsive UI):** Физические константы, размеры шрифтов, масштабы кораблей и планет автоматически рассчитываются исходя из разрешения экрана пользователя (`SW/SH`), обеспечивая идеальное отображение как на 1080p, так и на 4K мониторах.
3.  **Гибкие режимы игры:**
    * Режим на двоих игроков (PvP локально за одной клавиатурой).
    * Режим против продвинутого ИИ (Компьютера) с 3 уровнями сложности (*Новобранец, Опытный, Мастер*). Бот рассчитывает траектории с учетом притяжения планет и умеет уклоняться от угроз.
4.  **Уникальная система пауэрапов (Power-ups):**
    * 💛 **Тройной выстрел** — три снаряда веером.
    * 🔵 **Рассеянный огонь** — одновременный залп из 5 снарядов.
    * ❤ **Ремонт (+1 HP)** — восстановление здоровья корабля.
    * 🟣 **Спаренная пушка** — сдвоенный центральный огонь.
    * 🟢 **Энергетический щит** — неуязвимость на 3 секунды.
    * 🟠 **Гипер-тяга** — ускорение двигателей.
    * ⭐ **Снаряд-пробойник** — золотой снаряд, не исчезающий при контакте.
    * 🔴 **Самонаводящаяся ракета** — захватывает ближайшую цель и обходит гравитационные ловушки.
